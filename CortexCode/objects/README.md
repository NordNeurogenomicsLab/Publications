# Saved analysis objects

Saved fits, normalized assay caches and derived plotting objects are available in the [public Box release](https://ucdavis.box.com/s/jrmg33n2dcljxadenvx47ji8c6azg02s). Copy its `objects/` directory here, retaining paths. Binary files remain excluded from Git.

[Saved RDS/RData object list and roles](../SAVED_OBJECTS.md) · [Machine-readable inventory](../config/saved_objects.csv)

The original fitted WGCNA networks are stored separately in `data/upstream/WGCNA/WGCNA_objects/`. Figure-specific table caches under `objects/source_tables/` are created by notebook 00 from the CSV inputs.

See [INPUTS.md](../INPUTS.md) for the required directory layout and the release restoration instructions.
