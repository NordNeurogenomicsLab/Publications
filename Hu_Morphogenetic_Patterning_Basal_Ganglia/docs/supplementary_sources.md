# Supplementary analysis sources

The shared manuscript folder `MorphogeneticPatterningInTheMGEManuscript` contains the original Tables S1–S4 and Figure S7. They were inspected without changing the source files.

- Tables S1 and S2: VZ and MZ differential-expression statistics. All numerical records agree with the corresponding CSV inputs after identifying the gene-name date conversions listed in `supplement_gene_symbol_dates.tsv`.
- Table S3: the neuronal feature panel, exactly matching all 52 symbols and their order in `config/proj_neu_genes.txt`.
- Table S4, Sheet1 C2:X34: an anatomical region/marker reference. `config/anatomical_marker_reference.tsv` preserves each source row, marker label, region, and original annotation. Blank cells mean no recorded assertion; notes/question marks remain intact.
- Figure S7A: numerical MZ clusters and manual regional annotations. Figure S7A′: complete numerical-cluster age proportions. Figure S7B′–C′: marker-expression maps generated by script 04.

The anatomical marker reference is not a cell-level annotation table. It cannot by itself define a deterministic 15-cluster-to-eight-group aggregation for the main Figure 4D. No expression-similarity rule is substituted for the authors' final key.
