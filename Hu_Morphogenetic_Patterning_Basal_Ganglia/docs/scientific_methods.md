# Single-cell scientific methods

## Experimental design and count quantification

1538 lineage cells were induced with tamoxifen at E10.5, harvested from the MGE at E11.5 or E13.5, and selected by tdTomato FACS. The computational dataset contains one E11.5 library (`1538TE10H11`, 3,064 cells) and two E13.5 libraries (`1538TE10H13`, 1,374 cells; `JH4327_01_TE10H13`, 3,347 cells). Cell-level age contrasts describe these libraries; their p-values do not substitute for biological replicate inference.

The January 2026 processing used Cell Ranger 7.0.1, `refdata-gex-mm10-2020-A`, default gene-expression counting, 15 cores and 120 GB. This was a later reprocessing of the sequencing reads. Original RNA UMI values in the saved global object differ for the older libraries, so the exported RNA count matrices preserve the quantification that actually entered the historical R analysis. Original FASTQ-to-count version/settings for those libraries are still being traced. No inferred alignment settings are substituted for missing historical records.

## Quality control and tissue identity

The active QC code retains cells with more than 1,000 RNA UMIs and less than 20% mitochondrial UMIs (`^mt-`). The 5-MAD, 200-feature, and 15% mitochondrial flags in the exploratory notebook were diagnostic columns, not additional active filters. RNA UMIs and mitochondrial fractions are calculated before SCT.

The earlier libraries underwent POA/septum exclusion. The recovered 2023 VZ analysis notebook identifies marker-positive POA cells from the top 20% of nonzero expression for Igfbp5, Dbx1, or Hmx3, and septum cells from the top 50% for Spry1, Fgf8, or Zic4. Marker-guided labels train scAnnotatR SVM classifiers with a seeded 50/50 train/test split. POA, septum, and overlapping predictions are excluded. The executed 2023 code is supplied along with a structured classifier module. The notebook reports held-out AUCs of 0.9817 (POA) and 0.986 (septum); these are historical comments, not results of the present checks. Fresh fits save their own models, predictions, train/test membership, tuning summaries, and session information. The retained-cell table exports the exact manuscript selection for deterministic count-based analysis. The E13.5 GEX cells were rescued from a MULTI-seq preparation while explicitly ignoring poorly performing LMO barcodes; tissue identity was assessed using gene expression. Preliminary integration before classification used per-library SCT v1 with glmGamPoi. JH4327_01 was an MGE-only preparation and was added without that tissue-exclusion procedure.

## Global integration

The two older curated libraries are merged into one integration unit, as in the source notebook. This unit and the additional E13.5 library are SCT-normalized separately. The stored global models identify v1 SCT with the fitting-routine argument `method="poisson"`; this is part of SCT’s regularized negative-binomial modeling and does not impose Poisson noise throughout. In the global integration, a standalone exploratory glmGamPoi run on the new library was superseded by this integration-stage normalization. SCT integration uses 3,000 selected features, preparation of Pearson residuals, CCA anchors over PCs 1–30, and anchor weighting `k.weight=100`. Global PCA retains 25 PCs, chosen empirically using variance/scree inspection. UMAP uses PCs 1–25, 30 neighbors, cosine distance, `min.dist=0.3`, and seed 42. SNN construction uses 20 neighbors; Louvain clustering uses resolution 0.8 and seed 0. See the saved-object command report and scripts for parameters.

Hes1, Ascl1, and Dcx orient ventricular, subventricular, and postmitotic expression states. The annotation table preserves manuscript cluster assignments separately from new numerical cluster labels. Fresh runs can permute or split clusters and are compared to those reference annotations rather than substituting new numeric IDs into historical cell selections.

## Neuronal and progenitor feature panels

The August 2025 MZ analysis selects original global clusters 0, 1, 3, 8, 13, 16, 6, and 4. It restricts counts to the 52 neuronal specification/subtype/maturation genes listed in `config/proj_neu_genes.txt` before splitting by library and SCT reintegration. The aim is to emphasize neuronal subtype programs rather than unrelated sources of variability. This does not imply that all MZ cells are projection neurons. `SelectIntegrationFeatures(nfeatures=3000)` can only select genes present in the restricted matrix; it does not introduce thousands of additional genes.

The VZ/SVZ analysis selects original clusters 2, 15, 7, 14, 5, 12, 11, and 9 and uses the source progenitor panel in `config/progenitor_genes.txt`. The source's “221-gene” name describes its list length; duplicate symbols and missing aliases are deduplicated/intersected before fitting, and the actual used/missing features are recorded. This panel spans progenitor identity, signaling, neurogenesis, metabolism, and proliferation. No cell-cycle regression is applied in this custom-panel analysis, preserving developmental differences associated with cycling state.

Both panels use per-library SCT v2 normalization, SCT integration, 25-PC PCA, UMAP `min.dist=0.01`, and Louvain resolution 0.8. The smaller minimum distance emphasizes local neuronal/progenitor structure. Embeddings and cluster identities are transferred by matched cell ID to the full-expression objects. The MZ checkpoint includes its full-gene SCT v2 marker model. The progenitor checkpoint retains inherited global SCT v1 models for expression, cell-cycle scoring, and later within-cluster age comparisons. Its cluster-marker analysis separately fits a full-gene v2 model, saved as `VZ_SVZ_cluster_marker_model.rds` for marker testing and heatmaps. The scripts preserve these distinct checkpoint and marker stages. Before age tests, inherited models are prepared together with `PrepSCTFindMarkers`; subset tests use `recorrect_umi=FALSE` to use the already prepared counts consistently.

Progenitor cell-cycle annotations use Seurat's S/G2M gene lists converted to mouse symbol case, expression-matched controls, and module scores. The source's modified phase assignment calls G1 when both scores are below 0.1; otherwise the higher score determines S or G2M, with ties marked Undecided. `cell_cycle_annotation.R` preserves that boundary and records the phase gene lists. Cell-cycle state is annotated without regressing its scores from the custom-panel embedding.

## Differential expression and figures

Broad historical compartments use VZ clusters 2/15/5/12/7/14; SVZ 9/11/1; and MZ 3/8/4/0/6/16/13/10. This broad MZ definition differs from the later refined neuronal subset and is kept explicit. The four VZ clusters named for focused age comparisons are 2/7/5/14. The saved `Dev_classes` field is incomplete for the added library and is not silently used to discard those cells.

Age contrasts use full-gene SCT data after `PrepSCTFindMarkers`, Wilcoxon rank-sum tests, `min.pct=0.25`, and `logfc.threshold=0.25`. E11.5 is ident.1, so positive stored log2 fold change means higher expression at E11.5. Cluster markers use `FindAllMarkers(only.pos=TRUE)` with the same thresholds. Within-cluster age comparisons require at least three cells per age, excluding the source progenitor cluster with only two cells at one age. Tables retain raw and Bonferroni-adjusted p-values. Volcano plots display the negative of stored fold change so E13.5 is on the right, and use raw p-values as in the original plotting code. Each contrast labels its own 50 lowest-p-value genes; manual manuscript text placement and functional label colors are not statistical analysis steps. Supplied historical DE tables remain available; fresh tests write separate outputs.

Feature plots use SCT normalized expression, never integrated expression for effect-size testing. Top-marker heatmaps use full-gene SCT scaled values. Cluster proportions divide each age-specific cluster count by all selected MZ cells of that age. Figure 4D's eight anatomical labels require an author-confirmed mapping from the stored 15 neuronal clusters; marker similarity alone cannot establish an anatomical key. Scripts therefore expose numeric clusters and explicit denominator tables rather than inserting an unverified mapping.

## Source records

The source notebooks in `historical/` contain the original global analysis, the later custom-panel workflow, and the January realignment comparison. `saved_object_command_parameters.txt` records commands and model arguments extracted directly from the supplied objects. Transferred reductions can retain earlier command-history entries, so the custom-panel parameters are taken from their generating notebook rather than interpreting stale global command records as new fits. The repository provides executable methods and exact annotation inputs; the original fitted classifier objects and the final anatomical key remain data dependencies to resolve before claiming an identical end-to-end historical rerun.

Implementation references: [Seurat SCT normalization](https://satijalab.org/seurat/reference/sctransform), [Seurat differential expression](https://satijalab.org/seurat/reference/findmarkers), [scAnnotatR model training](https://bioconductor.org/packages/release/bioc/vignettes/scAnnotatR/inst/doc/training-basic-model.html). The recorded historical parameters take precedence over changing defaults in current documentation.
